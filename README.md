## Project Description

Task Manager is a simple web application developed using HTML, CSS, JavaScript, and Supabase.

The application allows users to add, edit, delete, and manage tasks. All tasks are stored in a Supabase PostgreSQL database.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed or incomplete
- Delete tasks
- Save tasks in the database
- Display task statistics

## Technologies

- HTML, CSS, JavaScript
- Supabase PostgreSQL
- Supabase REST API
- GitHub Pages
